# Cristine Ribeiro | Desenvolvedora Web

Portfólio e página comercial feitos com React + Vite + TypeScript + Tailwind CSS.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra a URL indicada no terminal (normalmente `http://localhost:5173`).

## Gerar build

```bash
npm run build
```

O site final é gerado na pasta `dist` e pode ser publicado em qualquer hospedagem de site estático.

## Editar projetos do portfólio

- Textos, links e tags: `src/data/projects.ts`
- Imagens: `public/portfolio/` (formato `.webp`, proporção 4:3)

## Contato e WhatsApp

Número, e-mail e redes ficam em `src/lib/contact.ts`.
